## Component findings and reuse decisions

| Area | Source review finding | Disposition |
|---|---|---|
| HTTP and retry | `client.HttpClient.request` enforces TLS, timeouts and bounded transient retries. `PisrsClient.probe` exercises shape on a cheap NPB GET. Legacy retries ignore `Retry-After` and use a generic method policy also used for paid POST. `fetch_text` returns decoded text. | Reuse dependency-injected client/test patterns, TLS and timeout defaults as starting points. Implement capped streaming, GET-only automatic retry, origin/redirect policy, and exact bytes. |
| Discovery and pagination | On main, `ACT_ENDPOINTS` has four paths and `_pages(total_key="total")` checks a name absent from the official envelope; short-page termination can silently stop on server caps. `0432371` adds all seven state paths, duplicate detection and strict totals. `84b72b1` covers 13 primary catalogues and disables stable-total enforcement for local act paths. It still relies on stable totals elsewhere and its normal catalogue import skips all projections, code lists and full response capture. | Reuse endpoint/provenance fixtures and progress guards. Implement proven termination rules and independent manifest comparison. |
| Identity and failure handling | `84b72b1 ExternalCatalogStore.synchronize` raises when `moped_plus_id`, EDA or SOP conflicts with a prior non-null value, or an existing local NPB link changes. OLC-85 records those two particular guards stopping seven nights. The upstream deltas were not adjudicated, so their legitimacy and specific bad rows remain unknown. The old guards protect against silent reinterpretation but provide no correction workflow. | Preserve the protective check as quarantine evidence. Implement audited versioned identity transitions and reviewed link resolution. |
| Text and provenance | State NPB by ID matches the sampled wire path. Legacy `fetch_text` passes decoded HTML to the parser. SQL `ON CONFLICT (text_id)` updates the same record and removes obsolete normalized block rows, so a repeated locator cannot independently recover prior representations after revision. Raw metadata variants use JSONB rather than full HTTP entity bytes. | Reuse controlled fetch shape; implement original body/revisions and separate parsed output. Archive authorized base text only after identity controls. |
| Parsing and chunking | Main and active `parse_html` traverse selected parent and descendant tags and call descendant-inclusive `get_text`, which can repeat nested text. The closed parser PR has regression material. Existing article classifiers, headings and deterministic chunking remain useful but do not prove table/annex fidelity or token limits. | Port classifier and unit examples with nested/table/annex/Unicode fixtures and byte-backed locators. Rework traversal and token boundaries. |
| PG, configuration and checkpoint | Parameterized SQL, DB identity/schema preflight, separate read-only connection, unique/FK checks, cooperative application lock and atomic file checkpoint are reusable patterns. Medo catalogue import applies separate store phases and has no source checkpoint in catalogs-only. Legacy runtime requires a fixed compatible schema, configuration and collection; the full run gates final checkpoint on vectors. | Model independently committed archive attempts and two transactional stage checkpoints. Do not port legacy tables or environment defaults. |
| Embeddings and Qdrant | Adapter preflights dimension/distance and reuses by point metadata. Main `_vector_contract_matches` can accept matching metadata without reading actual vector. Reconciler scrolls and checks keys with cycle protection. Legacy embedder checks list length/dimensions but not unique contiguous response indices or finite numbers and uses the generic retry path. | Reuse bounded scroll, payload type comparison, config validation and batch test design. Require vector readback, strict response permutation/finiteness, a durable paid request ledger and explicit generation policy. |

The confirmed engineering failures are incomplete main discovery, insufficient archival/identity evidence, and a legacy invariant policy that stalls on unresolved upstream deltas. Exact historical project decisions and the cause of the earlier HTTP 407 remain unverified. A single branch strategy cannot by itself correct those failures.
