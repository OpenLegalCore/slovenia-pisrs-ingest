# PIKI acceptance matrix

Each report records time in UTC and Europe/Ljubljana, actor/role, stage and release, spec/schema/index revisions, test input classification, observed result, sanitized evidence hash and corrective action. Use PASS, FAIL, NOT_VERIFIED, NOT_RUN. The official OpenAPI bytes and selected host state were independently checked; owner-operated PIKI controls later completed **17+24 bounded GETs with HTTP 200** (all three local catalog terminal profiles PASS_BOUNDED) and **one additional targeted state GET HTTP 200** (CELEX relationship NOT_VERIFIED). Effective Docker `/data/docker` and live containerd `/data/containerd` are PASS. The ZDR-1 saved base body check is NOT_RUN; dictionary membership remains NOT_RUN. These are **G1 sampled observations, not live full-source or runtime acceptance**. Source entitlement for sustained PIKI use, independent backup destination and final G0–G2 signoff remain open; G3–G5 runtime acceptance is NOT_RUN.

## Execution-to-acceptance traceability and signoff rules

**No new gates.** These rules give the implementation team deterministic success/failure conditions for the existing A01–A18 matrix. Every report contains the actual release, schema, source contract hash, requester authorization, exact namespace/locator denominator, observation cutoff and independent evidence references. A synthetic fixture PASS is not equivalent to a real PIKI staging PASS.

| Gate | Deliverable and required checks | Failure behavior |
|---|---|---|
| G0 | Effective /data bind/container roots, approved issuer source scope/rate, no conflicting project resources, named off-host recovery destination and custodian, approved proposed RPO/RTO. Record service grants as future G3/G4 preflight if not provisioned. | Any missing **pre-install decision** remains open; do not create services or claim installed readiness. |
| G1 | Pinned 26 GET operations, 15 schemas/125 mapped fields, bounded termination profiles, qualified state text locator and explicit handling of ambiguous links. Record known-positive and negative controls only with raw source evidence. | Unresolved optional CELEX/code edge is archived as UNRESOLVED, not fabricated; missing a **required** identity/scope rule blocks the affected class or documented owner-approved exception. |
| G2 | Full 20-table data contract and its invariants, 13+10+dictionary+state-text work plan, nightly, Qdrant/legal-date contract, rollback/recovery semantics and traceable A01–A18 tests; owner approves the actual specification commit and scope exclusions. | Documented open external conditions may be recorded but do not silently become PASS; unaddressed design choices prohibit formal approval. |
| G3 | From empty schema run reviewed migrations and a real authorized **full source→PG** capture, verify every endpoint manifest, raw body integrity, state locator/version history, interruption recovery, idempotence, read-only roles and tested fenced backup capture. | No SOURCE head promotion on missing required operation, unstable sweep, missing required text or identity collision. Do not substitute samples or counts for parity. |
| G4 | Separately owner-approved measured embedding budget, index generation with current and proven dated history, complete PG cached vectors and Qdrant full point/payload/vector parity, fence/rebuild proof. | Never auto-resend ambiguous paid POST; leave prior INDEX published and QA blocked during APPLYING. |
| G5 | Actual timer-driven nightly completion and failure/restart, bounded lag and alert proof, test-user dated query access, independent off-host encrypted backup **restored into isolated mounts**, measured RPO/RTO and corruption test, zero paid calls on restore. | A service merely running or archive files merely existing is not success; missing independent restoration or read-fence bypass is FAIL. |

For every G3+ catalogue include **two comparisons**: (1) source endpoint-qualified identity/payload manifest against independently recomputed persisted PG occurrences and (2) source text-locator/raw-response SHA-256 manifest against archived source_blob and source_artifact. Independently re-read SQL using a role that cannot modify candidate rows. A full dataset comparison requires terminal enumerations and an accepted snapshot/stable-period model; any unverified source boundary makes source-global point-in-time completeness NOT_VERIFIED even when PG contains every observed source row.

For G4+ Qdrant compare the full frozen PG eligible set against complete Qdrant scroll by **point identity, payload, actual vectors, dimensions, model and legal windows**, with zero orphan/missing point allowance. One collection temporarily blocks all QA reads during applying/recovery; measure the resulting downtime under the owner-approved maintenance SLO. A vector-cache mismatch cannot be fixed by paying for new embeddings without a new explicit approval.

**Signoff format:** GATE | scope | official source contract SHA | source snapshot/cutoff | repository commit | tested schema/release digest | exact denominator | PASS/FAIL/NOT_VERIFIED/NOT_RUN | evidence hashes | exceptions | authorized signer. G2 **documentation acceptance** is a decision on an immutable reviewed commit, *not* an assumption derived from published Git files. G3 deployment, initial authorized bulk fetch and G4 paid calls require distinct explicit permissions. The unverified issuer grant and independent backup endpoint belong to G0, not to speculative future code design.

## Coverage denominators

PostgreSQL catalogue denominator is the union of endpoint-qualified identities validated by A02, with membership retained even for overlapping records. Archive equality compares hashes of each canonical original response and approved text representation as well as identity/version sets. Report original text availability and normalized text success separately, with each unsupported/absent case reasoned and counted. History requires an accepted source temporal boundary. No complete sweep, unknown source snapshot semantics, or missing required identity leaves the applicable completeness figure **NOT_VERIFIED**.

Qdrant denominator is the frozen set of eligible unique PG chunk occurrences after the owner-selected legal/time/history and parse contract. Compare every ID, payload and vector against PG as A13 defines. Oversampling and counts cannot substitute for full parity. Report the frozen cutoff and index generation even when a newer source checkpoint exists.
