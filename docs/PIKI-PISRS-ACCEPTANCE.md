Each report records time in UTC and Europe/Ljubljana, actor/role, stage and release, spec/schema/index revisions, test input classification, observed result, sanitized evidence hash and corrective action. Use PASS, FAIL, NOT_VERIFIED, NOT_RUN. Current audit independently verified the public OpenAPI bytes and selected host inventory. The bounded authorized GET evidence is a recorded prior result. Runtime acceptance for the proposed deployment remains NOT_RUN.

## Coverage denominators

PostgreSQL catalogue denominator is the union of endpoint-qualified identities validated by A02, with membership retained even for overlapping records. Archive equality compares hashes of each canonical original response and approved text representation as well as identity/version sets. Report original text availability and normalized text success separately, with each unsupported/absent case reasoned and counted. History requires an accepted source temporal boundary. No complete sweep, unknown source snapshot semantics, or missing required identity leaves the applicable completeness figure **NOT_VERIFIED**.

Qdrant denominator is the frozen set of eligible unique PG chunk occurrences after the owner-selected legal/time/history and parse contract. Compare every ID, payload and vector against PG as A13 defines. Oversampling and counts cannot substitute for full parity. Report the frozen cutoff and index generation even when a newer source checkpoint exists.
