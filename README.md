# OpenLegalCore PISRS staging on PIKI

PIKI is the planned permanent staging installation of the OpenLegalCore Slovenian legislation ingest. It archives authorized PISRS catalogues, legal text and observable history in PostgreSQL, then publishes an independently verified Qdrant index for the approved use case. The [staging master](docs/PIKI-PISRS-MASTER.md) defines scope, dependencies and acceptance.

This branch is the **G0–G5 engineering-specification candidate**, not a deployed ingest or a final owner-accepted implementation baseline. The [Master](docs/PIKI-PISRS-MASTER.md#implementation-ready-specification-scope-authority-and-handoff) defines source coverage, document authority, phase boundaries and what requires formal signoff. The [environment](docs/PIKI-PISRS-ENV.md) and [API evidence](docs/PIKI-PISRS-API.md) distinguish owner-confirmed PISRS permission, completed bounded G1 positive examples and still-unverified source-wide coverage, without inventing rate limits. No schema, containers, full collection run or paid embeddings are authorized merely by publishing this branch. The existing legacy release/history remain available at [v0.1.0](https://github.com/OpenLegalCore/slovenia-pisrs-ingest/tree/v0.1.0).
